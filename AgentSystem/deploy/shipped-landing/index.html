1) Origin

FixMyY opened the lane for everything that followed.

FixMyY

Live

A facilities-management app built from a working YMCA maintenance workflow.

"I remember going to fixmyy.com for the first time and being amazed that I vibecoded a working facility management app." It was built to run work orders, preventive maintenance schedules, and equipment workflows from one place. The implementation used a React + Supabase stack with AI-assisted work-order parsing, and it shipped through security hardening, RLS recursion fixes, and performance cleanup documented in repo history.

Outlook: this foundation can be refreshed into a modern operations console for service-heavy organizations while preserving the practical maintenance-first workflow that made it useful.

2) Live products

WaveForge

Live

A music-video generator for release workflows.

WaveForge was built to let artists and producers move from song files to ready-to-publish visuals without running a full video team. It uses a web app plus a dedicated render worker stack, with productized integrations like MCP and an n8n node. The hardest parts were render-memory stability, onboarding flow breaks, and product-boundary issues in shared checkout/webhook infrastructure, all documented in the operating notes.

Outlook: continue conversion and reliability work before expanding into broader API and agency layers.

THE SYNDICATE

Framework

A swarm architecture with hard handoffs between drafting, gating, and execution.

The architecture was locked in May 2026 as a three-agent chain: SNIPER drafts, AUDITOR gates, and EXO ships. SNIPER handles prospect research, A/B/C DM drafting, and reply-triage drafts, then self-gates through an audit script before staging. AUDITOR enforces outbound gates for audit checks, ICP fit, strategic context, and service health with explicit veto authority, while EXO is the only actor allowed to execute external sends, deploys, and commits.

Workflow control is run as a state machine of folder moves: research, drafted, staged after audit PASS, sent after AUDITOR SHIP, back to drafted on REVISE, and cold_storage on HOLD. Each staged draft carries the message, an audit record, a fit note, and a verdict. Volume is capped at 3-5 sends per week, and EXO guardrails include never amending commits, never force-pushing main, never skipping git hooks, no Friday-afternoon deploys outside windows, and never echoing .env contents.

Outlook: the same separation-of-duties pattern can be generalized as a reusable governance model for high-risk autonomous outreach systems.
